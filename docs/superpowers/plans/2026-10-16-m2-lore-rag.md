# Milestone 2: Lore RAG and Bundle Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The DM looks up the world's lore before narrating. Lorebooks are written in Markdown, rendered to PDF, parsed with `ai_parse_document`, chunked into a Delta table and indexed in AI Search. A new `search_lore` tool retrieves passages for the current location, its neighbours and the global books. Every retrieval shows up as a 📚 turn event and a trace span. Everything is deployed with one bundle and a Makefile. This is **sandbox mode**: lore plus improvisation, no quest yet (the campaign design comes later).

**Architecture:**
- **Repo root:** gains `content/` (lorebooks plus `manifest.yaml`), a `pipelines/` uv project, a root `databricks.yml` bundle with `resources/*.yml`, and a `Makefile`.
- **Build:** the pure-Python **renderer** (`lore.render`) turns Markdown into PDFs. They're uploaded to a UC volume together with the manifest.
- **Ingest:** a serverless bundle **job** runs `pipelines/ingest_job.py`. It does `ai_parse_document` in Spark, then the pure-Python **chunker** (`lore.chunking`), then writes the `lore_chunks` Delta table with change data feed on. Finally it creates or syncs a Delta Sync AI Search index with managed `databricks-gte-large-en` embeddings.
- **Ownership:** the AI Search **endpoint** is a bundle resource. The **index** is created by the job, because a bundle-declared index would need its source table to exist at deploy time.
- **The DM:** gets a `search_lore` local tool. It reads `location_id` from graph state; the model supplies only the query. It calls `WorkspaceClient().vector_search_indexes.query_index`.

**Tech Stack:**
- Databricks Asset Bundles (CLI v1.20.0): `schemas`, `volumes`, `vector_search_endpoints` and `jobs` resources
- Serverless jobs (environment version 3) and `ai_parse_document` v2.0
- AI Search STANDARD endpoint
- Python ≥3.11 with `uv`, `markdown` and `fpdf2`, `pyyaml`
- The `databricks-sdk` vector search API
- Existing `dm/` stack from M1

**Spec:** `docs/superpowers/specs/2026-10-16-databricks-rpg-design.md`. This plan is milestone 2 of §15, and it builds on the merged M1 (`dm/`).

## Global Constraints

- Python `>=3.11`, `uv` for both `dm/` and `pipelines/`.
- The dev profile is `brickbots` and the dev catalog is `serverless_stable_brickbots_catalog`. Both are passed on the command line or put in `dm/.env`, which is gitignored. **Tracked code and config files never hard-code a profile, host, catalog, token or email.** (Plan documents name the dev values as instructions.) The bundle's `catalog` variable has no default.
- Schema `databricks_adventure`, volume `lore`, table `lore_chunks` and index `lore_index` are all in `${catalog}.${schema}`. The AI Search endpoint is called `databricks-adventure-search` (STANDARD). The embedding endpoint is `databricks-gte-large-en`.
- `lore_chunks` columns: `chunk_id STRING` (primary key), `chunk_text STRING`, `doc_type STRING`, `location_id STRING`, `source STRING`, `page INT`. Global books (`primer`, `rules`, `bestiary`) have `location_id = "global"`.
- `doc_type` is one of `location | primer | rules | bestiary`.
- Retrieval filter: `location_id IN (current, *exits of current, "global")`, with `num_results = 4`.
- **The model never supplies location.** `search_lore` reads it from state, the same way M1's `roll_check` reads the modifier.
- Setting: the **Kingdom of Sparkia**, played straight. All lore and prompts are in British English.
- Commit messages end with `Co-authored-by: Isaac <no-reply@databricks.com>`.

**Spec deltas made in this plan (recorded in Task 5):**
1. The **UC function promotion of `roll_check` moves from M2 to M3**. A UC function bound through `agent.toml` takes its arguments from the model, so the model would supply the stat modifier, which breaks "the DM never invents numbers". In M3 the character lives in Lakebase, so the function can look the modifier up itself.
2. The **AI Search index is created by the ingest job**, not declared in the bundle, because of the source-table ordering.
3. **Retrieval covers neighbouring locations**, so rumours about the next place are findable from where you stand.
4. **§11 Q1 is resolved:** `search_lore` is an agent-side tool; no managed AI Search MCP exists. **§11 Q2:** STANDARD is chosen for lowest query latency, with pricing still to check before release.

## Review Focus

1. **AI Search returns nothing, or the index isn't configured** (`LORE_INDEX` unset, the index not ready, an empty result). The turn still completes, the DM improvises in keeping with the world, and the tool returns a clear error or an empty `passages` list rather than raising. Pinned in Task 6.
2. **The ingest job runs twice.** A second `make deploy` doesn't duplicate chunks or fail on "index already exists": the table is overwritten and the index re-synced. Pinned in Tasks 3/4 (deterministic `chunk_id`s) and Task 5 (live re-run).
3. **A PDF fails to parse.** `ai_parse_document` reports `error_status`. That document is skipped with a logged warning, and the other documents are still indexed. Pinned in Task 4.
4. **Lore uses typographic characters** (curly quotes, em dashes, ellipses, accented names). The PDFs render without `fpdf2` latin-1 errors, and the text survives parsing. Pinned in Task 2.
5. **A long section exceeds the embedding window.** Chunks stay within `MAX_CHUNK_CHARS` and keep their heading path, so retrieval still finds them. Pinned in Task 3.

```markdown
# The Rules of Adventure

## Stats

Every adventurer has three stats: Might (strength, endurance and force of arms), Wits (magic, learning and sharp senses) and Charm (persuasion, deceit and presence). Each stat has a modifier between +0 and +3.

## Checks

When an action's outcome is uncertain, the adventurer makes a check: roll a twenty-sided die and add the matching stat's modifier. If the total meets or beats the difficulty, the action succeeds. Easy tasks have difficulty 8, normal tasks 12 and hard tasks 16. The Dungeon Master chooses the stat and the difficulty, and the dice decide the rest.

## Combat

In a fight, the attacker rolls a twenty-sided die and adds Might for weapons or Wits for spells. If the total meets or beats the defender's defence (10 plus their best defensive modifier), the attack hits and deals its weapon's damage. A longsword or ember wand deals a six-sided die plus 2, and a rapier a six-sided die plus 1.

## Hit Points and Being Downed

Hit points measure how much punishment an adventurer can take. Warriors start with 18, Bards with 14 and Mages with 12. An adventurer reduced to 0 hit points is downed. They wake later at the Medallion Inn with half their hit points and half their gold. Being downed is a setback, not the end of the adventure.

## Archetypes

Warriors (Might +3, Charm +1) carry a longsword, shield and rope. Mages (Wits +3, Charm +1) carry an ember wand, lantern and a satchel of runes. Bards (Charm +3, Might +1) carry a rapier, a lute and a letter of introduction.
```

```python
"""Read the world manifest (content/manifest.yaml)."""

from pathlib import Path

import yaml


def load_manifest(path: str | Path) -> dict:
    return yaml.safe_load(Path(path).read_text())


def doc_metadata(manifest: dict) -> dict[str, dict]:
    """Map each lorebook's PDF stem to the metadata stored on its chunks."""
    return {
        Path(d["file"]).stem: {"doc_type": d["doc_type"], "location_id": d["location_id"]}
        for d in manifest["documents"]
    }
```

`pipelines/lore/render.py`:
```python
"""Render Markdown lorebooks into styled PDF "campaign books".

fpdf2's built-in fonts are latin-1 only, so typographic characters are normalised first.
That keeps the build free of system font dependencies.
"""

import sys
from pathlib import Path

import markdown
from fpdf import FPDF

_REPLACEMENTS = {
    "‘": "'", "’": "'", "“": '"', "”": '"',
    "–": "-", "—": "-", "…": "...", " ": " ",
}


def normalise_text(text: str) -> str:
    for src, dst in _REPLACEMENTS.items():
        text = text.replace(src, dst)
    return text.encode("latin-1", errors="ignore").decode("latin-1")


def render_pdf(markdown_text: str) -> bytes:
    html = markdown.markdown(normalise_text(markdown_text))
    pdf = FPDF(format="A5")
    pdf.set_margins(16, 16, 16)
    pdf.set_auto_page_break(auto=True, margin=16)
    pdf.add_page()
    pdf.set_font("Times", size=11)
    pdf.write_html(html)
    return bytes(pdf.output())


def main(argv: list[str] | None = None) -> int:
    args = sys.argv[1:] if argv is None else argv
    if len(args) != 2:
        print("usage: python -m lore.render <lore_dir> <out_dir>", file=sys.stderr)
        return 2
    src, out = Path(args[0]), Path(args[1])
    out.mkdir(parents=True, exist_ok=True)
    for md in sorted(src.glob("*.md")):
        (out / f"{md.stem}.pdf").write_bytes(render_pdf(md.read_text()))
        print(f"rendered {md.name}")
    return 0


if __name__ == "__main__":
    raise SystemExit(main())
```

- Produces:
  - `MAX_CHUNK_CHARS = 1800`
  - `SKIP_TYPES = {"page_header", "page_footer", "page_number"}`
  - `@dataclass(frozen=True) Chunk(chunk_id: str, chunk_text: str, doc_type: str, location_id: str, source: str, page: int)`
  - `chunk_document(parsed: dict, source: str, doc_type: str, location_id: str) -> list[Chunk]`
- Behaviour:
  - A `title` element sets the heading path to `[title]`, and a `section_header` sets it to `[title, header]`. Each starts a new chunk.
  - Chunk text is `"<heading path joined with ' › '>\n\n<element contents joined by blank lines>"`.
  - `page` is the 1-based page of the chunk's first body element.
  - A chunk that would pass `MAX_CHUNK_CHARS` is split at element boundaries, and each part keeps the heading path.
  - `chunk_id` is `"<source>-<nnn>"`, sequential from 000, so re-runs are deterministic.
  - Headings with no body produce no chunk.

```python
"""Turn ai_parse_document output into retrieval chunks, one per section, with heading paths."""

from dataclasses import dataclass

MAX_CHUNK_CHARS = 1800
SKIP_TYPES = {"page_header", "page_footer", "page_number"}
_SEP = " › "


@dataclass(frozen=True)
class Chunk:
    chunk_id: str
    chunk_text: str
    doc_type: str
    location_id: str
    source: str
    page: int


def _page(element: dict) -> int:
    bbox = element.get("bbox") or []
    return (bbox[0].get("page_id", 0) if bbox else 0) + 1


def chunk_document(parsed: dict, source: str, doc_type: str, location_id: str) -> list[Chunk]:
    chunks: list[Chunk] = []
    title: str | None = None
    path: list[str] = []
    body: list[str] = []
    first_page = 1

    def flush() -> None:
        nonlocal body
        if body:
            text = _SEP.join(path) + "\n\n" + "\n\n".join(body)
            chunks.append(Chunk(f"{source}-{len(chunks):03d}", text, doc_type, location_id, source, first_page))
        body = []

    for element in parsed.get("document", {}).get("elements", []):
        kind, content = element.get("type"), (element.get("content") or "").strip()
        if kind in SKIP_TYPES or not content:
            continue
        if kind == "title":
            flush()
            title, path = content, [content]
        elif kind == "section_header":
            flush()
            path = [title, content] if title else [content]
        else:
            prefix_len = len(_SEP.join(path)) + 2
            if body and prefix_len + len("\n\n".join([*body, content])) > MAX_CHUNK_CHARS:
                flush()
            if not body:
                first_page = _page(element)
            body.append(content)
    flush()
    return chunks
```

`pipelines/ingest_job.py`:
```python
"""Serverless job: parse lorebook PDFs, chunk them, write lore_chunks and sync the AI Search index.

Run by the `ingest_lore` bundle job. The pure helpers (chunks_for_rows, index_spec) are unit
tested. main() needs Spark and a workspace.
"""

import argparse
import json
import logging
import sys
import time
from pathlib import PurePosixPath

logger = logging.getLogger("ingest_lore")
COLUMNS = ["chunk_id", "chunk_text", "doc_type", "location_id", "source", "page"]


def chunks_for_rows(rows, meta):
    from lore.chunking import chunk_document

    chunks, skipped = [], []
    for path, doc_json in rows:
        source = PurePosixPath(path).stem
        parsed = json.loads(doc_json)
        if parsed.get("error_status") or source not in meta:
            logger.warning("skipping %s (parse errors or not in manifest)", source)
            skipped.append(source)
            continue
        chunks.extend(chunk_document(parsed, source=source, **meta[source]))
    return chunks, skipped


def index_spec(source_table, embedding_endpoint):
    return {
        "source_table": source_table,
        "pipeline_type": "TRIGGERED",
        "embedding_source_columns": [
            {"name": "chunk_text", "embedding_model_endpoint_name": embedding_endpoint}
        ],
        "columns_to_sync": COLUMNS,
    }


def _wait(check, what, timeout_s=1800, every_s=20):
    deadline = time.time() + timeout_s
    while not check():
        if time.time() > deadline:
            raise TimeoutError(f"timed out waiting for {what}")
        logger.info("waiting for %s", what)
        time.sleep(every_s)


def main(argv=None):
    p = argparse.ArgumentParser()
    for name in ("--catalog", "--schema", "--endpoint", "--embedding-endpoint", "--src"):
        p.add_argument(name, required=True)
    a = p.parse_args(argv)
    sys.path.insert(0, a.src)
    logging.basicConfig(level=logging.INFO)

    from databricks.sdk import WorkspaceClient
    from databricks.sdk.service.vectorsearch import (
        DeltaSyncVectorIndexSpecRequest,
        EmbeddingSourceColumn,
        EndpointStatusState,
        PipelineType,
        VectorIndexType,
    )
    from lore.manifest import doc_metadata, load_manifest
    from pyspark.sql import SparkSession

    spark = SparkSession.builder.getOrCreate()
    volume = f"/Volumes/{a.catalog}/{a.schema}/lore"
    table = f"{a.catalog}.{a.schema}.lore_chunks"
    index_name = f"{a.catalog}.{a.schema}.lore_index"

    meta = doc_metadata(load_manifest(f"{volume}/manifest.yaml"))
    rows = spark.sql(
        f"SELECT path, to_json(ai_parse_document(content, map('version', '2.0'))) AS doc_json "
        f"FROM read_files('{volume}/pdfs', format => 'binaryFile')"
    ).collect()
    chunks, skipped = chunks_for_rows([(r.path, r.doc_json) for r in rows], meta)
    if not chunks:
        raise RuntimeError(f"no chunks produced (skipped: {skipped})")
    logger.info("%d chunks from %d documents; skipped %s", len(chunks), len(rows) - len(skipped), skipped)

    spark.sql(
        f"CREATE TABLE IF NOT EXISTS {table} (chunk_id STRING NOT NULL, chunk_text STRING, "
        f"doc_type STRING, location_id STRING, source STRING, page INT) "
        f"TBLPROPERTIES (delta.enableChangeDataFeed = true)"
    )
    df = spark.createDataFrame([[getattr(c, col) for col in COLUMNS] for c in chunks], spark.table(table).schema)
    df.write.mode("overwrite").option("overwriteSchema", "false").saveAsTable(table)

    w = WorkspaceClient()
    _wait(
        lambda: w.vector_search_endpoints.get_endpoint(a.endpoint).endpoint_status.state
        == EndpointStatusState.ONLINE,
        f"endpoint {a.endpoint}",
    )
    existing = {i.name for i in w.vector_search_indexes.list_indexes(a.endpoint)}
    if index_name in existing:
        w.vector_search_indexes.sync_index(index_name)
        logger.info("synced %s", index_name)
    else:
        spec = index_spec(table, a.embedding_endpoint)
        w.vector_search_indexes.create_index(
            name=index_name,
            endpoint_name=a.endpoint,
            primary_key="chunk_id",
            index_type=VectorIndexType.DELTA_SYNC,
            delta_sync_index_spec=DeltaSyncVectorIndexSpecRequest(
                source_table=spec["source_table"],
                pipeline_type=PipelineType.TRIGGERED,
                embedding_source_columns=[EmbeddingSourceColumn(**c) for c in spec["embedding_source_columns"]],
                columns_to_sync=spec["columns_to_sync"],
            ),
        )
        logger.info("created %s", index_name)
    _wait(lambda: bool(w.vector_search_indexes.get_index(index_name).status.ready), f"index {index_name}")
    logger.info("index %s ready", index_name)


if __name__ == "__main__":
    main()
```

```python
"""Lore tool: the DM looks up the world's lorebooks (AI Search) before describing it."""

import json
import os
from typing import Annotated, Callable

from databricks_agentkit import workspace_client
from langchain_core.tools import tool
from langgraph.prebuilt import InjectedState

from rpg.world import LOCATIONS

NUM_RESULTS = 4
COLUMNS = ["chunk_text", "source", "page", "doc_type", "location_id"]


def scope(location_id: str) -> list[str]:
    """Lore visible from a location: its own, its neighbours' (rumours travel) and the global books."""
    exits = list(LOCATIONS[location_id].exits) if location_id in LOCATIONS else []
    return [location_id, *exits, "global"]


def _query_index(query: str, locations: list[str]) -> list[dict]:
    index = os.getenv("LORE_INDEX")
    if not index:
        raise RuntimeError("LORE_INDEX is not set")
    response = workspace_client().vector_search_indexes.query_index(
        index_name=index,
        columns=COLUMNS,
        query_text=query,
        num_results=NUM_RESULTS,
        filters_json=json.dumps({"location_id": locations}),
    )
    names = [c.name for c in response.manifest.columns]
    passages = []
    for row in response.result.data_array or []:
        r = dict(zip(names, row))
        passages.append({
            "text": r["chunk_text"], "source": r["source"], "page": int(r["page"]),
            "doc_type": r["doc_type"], "location_id": r["location_id"],
        })
    return passages


SEARCH: Callable[[str, list[str]], list[dict]] = _query_index


@tool
def search_lore(query: str, state: Annotated[dict, InjectedState]) -> dict:
    """Search the Kingdom of Sparkia's lorebooks for places, people, creatures, history and rules.

    Call this before describing anything the player hasn't seen yet, before introducing a named
    character or creature, and whenever you need a rule. Write a short natural-language query
    such as "the ferryman at the Delta Crossing". Stay consistent with what it returns.
    """
    try:
        passages = SEARCH(query, scope(state.get("location_id", "")))
    except Exception as e:  # noqa: BLE001 - lore outages must not break the turn
        return {"error": f"lore unavailable: {e}"}
    return {"query": query, "passages": passages}
```

```python
def _roll_event(r: dict) -> TurnEvent:
    verdict = "success" if r["success"] else "failure"
    summary = (
        f"{r['stat'].title()} check: {r['roll']} {r['modifier']:+d} = {r['total']} "
        f"vs DC {r['dc']}, {verdict}"
    )
    return TurnEvent(type="roll", summary=summary, detail=r)


def _lore_event(r: dict) -> TurnEvent:
    passages = r.get("passages", [])
    sources = ", ".join(dict.fromkeys(p["source"] for p in passages)) or "nothing found"
    summary = f"Lore: {len(passages)} passages for '{r['query']}' ({sources})"
    return TurnEvent(type="lore", summary=summary, detail=r)


_EVENT_BUILDERS = {"roll_check": _roll_event, "search_lore": _lore_event}


def turn_events(messages: list[AnyMessage]) -> list[TurnEvent]:
    """Build curtain events in code from this turn's successful tool results."""
    events = []
    for m in _current_turn(messages):
        build = _EVENT_BUILDERS.get(getattr(m, "name", None)) if isinstance(m, ToolMessage) else None
        r = _tool_result(m) if build else None
        if r and "error" not in r:
            events.append(build(r))
    return events
```
