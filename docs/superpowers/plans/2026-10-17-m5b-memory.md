# M5b Memory That Learns From Play Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The DM records every turn as plain messages in a transcript session store. The Dreamer pipeline distils those on a schedule, and an end-of-adventure extraction distils them at once, so long-term memory learns from play.

**Architecture:**
- `agent/transcripts.py` wraps the AgentKit SDK.
- `runtime/adapter.py` calls it after each turn, and on `game_over`.
- Deploy creates the store, grants the DM `WRITE`, and passes `TRANSCRIPT_STORE`.
- `devtools/memory_pipeline.py` points `dm-dreamer` at the transcript store.
- Recall moves to the SDK's `memory_stores.get(...).search(...)`.

**Tech Stack:** Python 3.12, `databricks-agentbricks` 0.5.1 (`databricks_agentkit.AgentKitClient`), the `agentbricks` CLI, LangGraph (unchanged), pytest with a fake AgentKit client.

**Spec:** `docs/superpowers/specs/2026-10-17-m5b-memory-design.md`.

## Global Constraints

- **Item shape:** transcript items are `{"type": "message", "role": "user"|"assistant", "content": str, "invocation_id": str|None}`.
- **The transcript store name** is the `[session_store]` name in `dm/agent.toml` with a trailing `-sessions` replaced by `-transcripts`.
- **Blocked words never reach the transcript:** a turn with a `guardrail` event records `agent.guardrails.REFUSED_PLACEHOLDER` as the player's text.
- **Transcripts and distilling never break a turn:** failures are logged and swallowed. An unset `TRANSCRIPT_STORE` or `AGENT_MEMORY_STORE` is a no-op.
- **Unchanged:** the checkpointer store (`dm-vhiyme-sessions`) and `memory_tools`.
- **The pipeline:** `dm-dreamer`, `--trigger scheduled`, `--model system.ai.claude-sonnet-4-5`, `--instructions @../content/dreamer-instructions.md`.
- **Profile:** `brickbots` for every live step (the user's choice; never pick another). The catalog is `serverless_stable_brickbots_catalog`.
- **Public repo:** no hosts, IDs, emails or tokens in committed files.
- **Commits:** messages end with `Co-authored-by: Isaac <no-reply@databricks.com>`. Don't push; the user decides.
- **Language:** British English in prose and comments.

## Review Focus

1. **Actor mismatch.** The transcript session's `actor_id` must equal the actor `memory_tools` and `recall_memories` use (the adapter's `_player(...)`). Otherwise distilled memories land on a different actor and are never recalled. Pinned in Task 2, and live in Task 5.
2. **The first turn of a session.** The transcript session doesn't exist yet, so `record_turn` must add it and then append. A second turn must reuse it, not fail on "already exists". Pinned in Task 1.
3. **Recovery replays.** The same `invocation_id` recorded twice must append once. Pinned in Task 1.
4. **The deployed build lacks the Dreamer instructions file** (the build copies `dm/` only). End-of-game extraction then runs with platform defaults. Pinned in Task 4: the build copies the file, and the loader falls back to `None`.
5. **An old pipeline left on the checkpoint store.** It would keep running on unreadable blobs. Pinned in Task 4: `memory_pipeline` deletes it.

```python
"""Turn transcripts for long-term memory, in a session store the Dreamer pipeline can read.

The LangGraph checkpointer's session store holds msgpack checkpoint blobs, which the memory
pipeline can't distil. Per the platform tutorial for LangGraph agents, each turn is also written
here as plain user/assistant messages, under the same actor and session as the checkpointer.
"""

import logging
import os
import tomllib
from pathlib import Path

from agent.memory import resolve_memory_store

logger = logging.getLogger(__name__)

AGENT_TOML = Path(__file__).resolve().parents[1] / "agent.toml"
# The Dreamer instructions: the repo's content/ in dev, copied next to agent.toml in the deploy build.
_INSTRUCTIONS = (Path(__file__).resolve().parents[2] / "content" / "dreamer-instructions.md",
                 Path(__file__).resolve().parents[1] / "dreamer-instructions.md")


def transcript_store_name(toml_path: Path = AGENT_TOML) -> str:
    name = tomllib.loads(toml_path.read_text())["session_store"]["name"]
    return name.removesuffix("-sessions") + "-transcripts"


def dreamer_instructions() -> str | None:
    for path in _INSTRUCTIONS:
        if path.is_file():
            return path.read_text()
    return None


def _client(client):
    if client is not None:
        return client
    from databricks_agentkit import AgentKitClient, workspace_client

    return AgentKitClient(workspace_client())


def _session(client, actor: str, session_id: str, *, create: bool):
    store = client.session_stores.get(os.environ["TRANSCRIPT_STORE"])
    try:
        return store.get(session_id)
    except Exception:  # noqa: BLE001 - not found on a session's first turn
        if not create:
            raise
        return store.add(actor_id=actor, session_id=session_id)


def record_turn(actor: str, session_id: str, player_text: str | None, reply: str, invocation_id: str | None,
                client=None) -> None:
    """Append this turn as plain messages. Never raises: memory is a bonus, the turn is not."""
    if not os.getenv("TRANSCRIPT_STORE"):
        return
    try:
        session = _session(_client(client), actor, session_id, create=True)
        latest = next(iter(session.list_items(page_size=1, order_by="create_time desc")), None)
        if invocation_id and latest is not None and (latest.data or {}).get("invocation_id") == invocation_id:
            return  # a recovery replay of a turn already recorded
        items = [{"type": "message", "role": "user", "content": player_text, "invocation_id": invocation_id}
                 ] if player_text else []
        items.append({"type": "message", "role": "assistant", "content": reply, "invocation_id": invocation_id})
        session.append_items(items)
    except Exception:  # noqa: BLE001 - never break the turn
        logger.warning("recording the transcript failed", exc_info=True)


def distil_adventure(actor: str, session_id: str, client=None) -> list[str]:
    """Distil a finished adventure into long-term memories now; returns what was learned."""
    memory_store = resolve_memory_store()
    if not os.getenv("TRANSCRIPT_STORE") or not memory_store:
        return []
    try:
        session = _session(_client(client), actor, session_id, create=False)
        entries = session.extract_memories(memory_store=memory_store, instructions=dreamer_instructions())
        return [e.content for e in entries if getattr(e, "content", None)]
    except Exception:  # noqa: BLE001 - never break the final turn
        logger.warning("distilling the adventure failed", exc_info=True)
        return []
```

```python
def turn_transcript(agent_input: Any, turn: dict) -> tuple[str | None, str]:
    """What the transcript records for a turn: the player's words (or the placeholder) and the reply."""
    messages = agent_input.get("messages") if isinstance(agent_input, dict) else None
    users = [m.get("content") for m in messages or [] if isinstance(m, dict) and m.get("role") == "user"]
    player = users[-1] if users and isinstance(users[-1], str) and users[-1].strip() else None
    if player is not None and any(e.get("type") == "guardrail" for e in turn.get("events") or []):
        player = REFUSED_PLACEHOLDER  # blocked words never reach the transcript or memory
    choices = "\n".join(f"- {c}" for c in turn.get("choices") or [])
    reply = (turn.get("narration") or "") + (f"\n\n{choices}" if choices else "")
    return player, reply
```

"""The DM's transcript session store, which the Dreamer pipeline distils (see agent/transcripts.py)."""

import sys


def ensure_store(client, name: str) -> bool:
    """Create the store if it's missing. Returns True when it was created."""
    try:
        client.session_stores.get(name)
        return False
    except Exception:  # noqa: BLE001 - not found
        client.session_stores.create(name, description="Databricks Adventure: turn transcripts for the Dreamer")
        return True


def grant_store(client, name: str, sp: str) -> None:
    client.session_stores.get(name).grant_permission(sp, permission="WRITE")


def main(argv: list[str] | None = None) -> int:
    args = sys.argv[1:] if argv is None else argv
    if len(args) != 1:
        print("usage: python -m devtools.transcripts_store <profile>", file=sys.stderr)
        return 2
    from databricks.sdk import WorkspaceClient
    from databricks_agentkit import AgentKitClient

    from agent.transcripts import transcript_store_name

    name = transcript_store_name()
    created = ensure_store(AgentKitClient(WorkspaceClient(profile=args[0])), name)
    print(f"transcript store {name}: {'created' if created else 'exists'}")
    return 0


if __name__ == "__main__":
    raise SystemExit(main())

```python
"""make memory-pipeline: exactly one Dreamer, dm-dreamer, distilling the transcript store.

A pipeline's session store can't be changed in place, so one left on the checkpointer's store
(msgpack blobs it can't read) is deleted and recreated.
"""

import json
import sys
import tomllib
from pathlib import Path

from devtools.grants import _run

DISPLAY_NAME = "dm-dreamer"
MODEL = "system.ai.claude-sonnet-4-5"
INSTRUCTIONS = "@../content/dreamer-instructions.md"


def plan(pipelines: list[dict], memory_store: str, transcript_store: str) -> tuple[list[str], bool]:
    ours = [p for p in pipelines
            if p.get("display_name") == DISPLAY_NAME and p.get("memory_store") == f"memory-stores/{memory_store}"]
    keep = [p for p in ours if p.get("session_store") == f"session-stores/{transcript_store}"]
    return [p["name"] for p in ours if p not in keep], not keep


def main(argv: list[str] | None = None) -> int:
    args = sys.argv[1:] if argv is None else argv
    if len(args) != 1:
        print("usage: python -m devtools.memory_pipeline <profile>", file=sys.stderr)
        return 2
    profile = args[0]
    from databricks.sdk import WorkspaceClient

    from agent.transcripts import AGENT_TOML, transcript_store_name

    memory_store = tomllib.loads(Path(AGENT_TOML).read_text())["memory_store"]["name"]
    transcripts = transcript_store_name()
    listed = WorkspaceClient(profile=profile).api_client.do("GET", "/api/2.0/agents/memory-pipelines")
    delete, create = plan(listed.get("memory_pipelines") or [], memory_store, transcripts)
    for name in delete:
        _run(["agentbricks", "--profile", profile, "memory", "pipeline", "delete", name])
        print(f"deleted {name} (it read the checkpoint store)")
    if create:
        _run(["agentbricks", "--profile", profile, "memory", "pipeline", "create", "--memory-store", memory_store,
              "--session-store", transcripts, "--display-name", DISPLAY_NAME, "--model", MODEL,
              "--instructions", INSTRUCTIONS, "--trigger", "scheduled"])
        print(f"created {DISPLAY_NAME} on {transcripts}")
    else:
        print(f"{DISPLAY_NAME} already distils {transcripts}")
    return 0


if __name__ == "__main__":
    raise SystemExit(main())
```
