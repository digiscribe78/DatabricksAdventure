# Milestone 4: The Game App (AppKit) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A playable retro game in the browser. A Databricks **AppKit** app, `databricks-adventure`, has:
- a **title screen**: new adventure (name + Warrior/Mage/Bard), or Continue a save;
- the **game screen** in layout A, style B: scene panel, narration, choices, free text and character strip;
- the **Scrying Glass**: live graph-node lights, the turn's events with "what's this?" explainers, timing, and a link to the traces.

It talks to the deployed DM *as the signed-in player*.

**Architecture and findings (verified 2026-10-16):**
- **Token forwarding works.** A spike app forwarded `x-forwarded-access-token` (default user scopes only) to `agent-bricks-dm` and got 200. The DM saw the **same player hash** as direct calls. This resolves spec §11 Q4.
- **The game app never touches Lakebase.** It can't reproduce the DM's per-principal player hash, so the **DM returns the game snapshot** (sheet, location, exits, flags, NPC moods, but never NPC secrets) and serves `list_adventures`. The DM stays the single door to game state.
- **Resuming a save:** the runtime namespaces `session_id` per user, so the DM stores the client's raw `client_session_id`, and Continue sends that back.
- **DM SSE format:** blocks of `id:` / `event:` / `data:` lines. The events are `run.started`, `node` (`{"node": ...}`), `message`, `delta`, `turn` (`{"turn": ...}`) and `run.completed`. The server forwards only `run.started`, `node`, `turn`, `game`, `run.completed` and `run.failed`. That drops ~130 `delta` and the bulky `message` events, which carry lore.
- **AppKit 0.84 scaffold** (`databricks apps init --name … --run none --package-manager npm`): `server/server.ts` (`createApp({plugins:[server()]})`), React and Vite in `client/`, vitest (node env, `passWithNoTests`), and its own `databricks.yml` with a **hard-coded workspace host, which we remove**. Routes are added with `appkit.server.extend(app => …)` in `onPluginsReady`.
- **The DM URL is resolved at runtime:** service-principal M2M token → `GET /api/2.0/apps/agent-bricks-dm` → `.url`, cached. The game app's bundle declares an app resource on `agent-bricks-dm` (`CAN_USE`). `DM_URL` and `DM_DEV_TOKEN` env vars override this for local dev.

**Tech Stack:** AppKit 0.84 (Express server plus React/Vite client), TypeScript, vitest, Databricks Asset Bundles (`apps` resource), and the M3b DM (Python).

**Spec:** `docs/superpowers/specs/2026-10-16-databricks-rpg-design.md`, §9 (the game app), and layout A / style B mockups in `docs/design/mockups/`. Builds on M3b (`m3b-deploy`, PR #5).

## Global Constraints

- The app name is `databricks-adventure` (20 characters, at most 26), in `app/`. Node 22 and npm. Don't override the `@databricks/appkit` versions that `databricks apps init` sets.
- **The player's token is forwarded, never the app's.** Every DM call uses `Authorization: Bearer <x-forwarded-access-token>`. If that header is missing (and there's no `DM_DEV_TOKEN`), return 401.
- **The browser never sees NPC secrets, lore passages or DM drafts.** The game snapshot excludes `secrets`, and the server drops `message` and `delta` events.
- No workspace host, app URL, IDs or emails in tracked files. `app/.env` is gitignored.
- Style B: VT323 for body text and Press Start 2P for titles (Google Fonts); gilded frames `#c8a24a`; background `#1b1424`; parchment text `#eadfc8`; Scrying Glass text `#b9a8ff` with gold `#f2c46b` titles. It must stay readable for 60 minutes.
- British English throughout the UI copy.
- Commit messages end with `Co-authored-by: Isaac <no-reply@databricks.com>`. Commits always go in their own shell command.

**Spec deltas (recorded in Task 6):**
1. §9: the app reads game state from the DM's snapshot, not from Lakebase. The app has no Lakebase access.
2. §7: `adventures.client_session_id` exists for Continue.
3. §9: the trace link goes to the DM's trace experiment page (a per-trace deep link comes later).

## Review Focus

1. **The forwarded token is missing** (local run without `DM_DEV_TOKEN`, or a misconfigured app). Return a 401 with a clear message. Never fall back to the app's service principal, which would merge every player into one. Pinned in Task 2.
2. **The DM stream drops or errors mid-turn.** The UI leaves its busy state, shows an in-world error with a "try again" option, and the game snapshot stays at its last good value. Pinned in Task 4.
3. **SSE chunk boundaries split an event**, or one chunk holds several events. The parsers in both the server filter and the client handle partial blocks. Pinned in Tasks 2 and 4.
4. **The game snapshot leaks NPC secrets or lore to the browser.** It never includes them. Pinned in Tasks 1 and 2.
5. **A player continues another player's adventure** by pasting a `client_session_id`. The runtime namespaces session IDs per user, so it maps to a different (empty) session, and the DM rejects it with "send new_game first". Pinned in Task 1.

```python
_CLIENT_REF = re.compile(r"^[A-Za-z0-9-]{1,64}$")


def _client_session_id(payload: dict[str, Any]) -> str | None:
    ref = payload.get("client_session_id")
    if ref is None:
        return None
    if not (isinstance(ref, str) and _CLIENT_REF.fullmatch(ref)):
        raise ValueError("client_session_id must be 1-64 letters, digits or hyphens")
    return ref


def game_snapshot(game) -> dict:
    """What the browser may see: no NPC secrets, no lore, no drafts."""
    here = LOCATIONS[game.location_id]
    host = os.getenv("DATABRICKS_HOST", "").removeprefix("https://").rstrip("/")
    exp = os.getenv("MLFLOW_EXPERIMENT_ID")
    return {
        "character": game.character.model_dump(),
        "location_id": game.location_id,
        "location_name": here.name,
        "exits": [{"id": e, "name": LOCATIONS[e].name} for e in here.exits if e in LOCATIONS],
        "flags": dict(game.flags),
        "npcs": [{"npc_id": n.npc_id, "name": n.name, "disposition": n.disposition} for n in game.npcs],
        "traces_url": f"https://{host}/ml/experiments/{exp}/traces" if host and exp else None,
    }
```

### Task 2: Scaffold the AppKit app and add the DM proxy

**Files:**
- Create: `app/` (scaffolded), `app/server/dm.ts`, `app/server/dm.test.ts`
- Modify: `app/server/server.ts`, `app/app.yaml`, `app/databricks.yml`, `.gitignore`

**Interfaces:**
- Produces (in `app/server/dm.ts`):
  - `FORWARD_EVENTS = new Set(["run.started", "node", "turn", "game", "run.completed", "run.failed"])`
  - `userToken(headers: Record<string, string | string[] | undefined>, env = process.env): string`. It uses `x-forwarded-access-token`, else `env.DM_DEV_TOKEN`, else throws `HttpError(401, ...)`.
  - `class HttpError extends Error { status: number }`
  - `invocationBody(input: TurnInput, sessionId: string, stream: boolean): object`, where `TurnInput = { message?: string; newGame?: { name: string; archetype: "warrior" | "mage" | "bard" }; listAdventures?: boolean }`. It sets `client_session_id = sessionId` for new games.
  - `filterSSE(buffer: string): { out: string; rest: string }`. It splits on blank lines, keeps complete blocks whose `event:` is in `FORWARD_EVENTS`, and returns the trailing partial block as `rest`.
  - `normaliseHost(h: string): string`, which returns `https://<host>` with no trailing slash
  - `resolveDmUrl(env = process.env, fetchFn = fetch): Promise<string>`. `env.DM_URL` wins; otherwise it uses an M2M token (`DATABRICKS_CLIENT_ID` and `DATABRICKS_CLIENT_SECRET` against `${host}/oidc/v1/token`), then `GET ${host}/api/2.0/apps/${DM_APP_NAME}` and its `.url`, cached.
- Routes: `GET /api/health`, `GET /api/adventures`, and `POST /api/turn` with body `{ sessionId: string, message?: string, newGame?: {...} }`, which streams the filtered SSE back.

```typescript
import { randomUUID } from 'node:crypto';

export const FORWARD_EVENTS = new Set(['run.started', 'node', 'turn', 'game', 'run.completed', 'run.failed']);

export class HttpError extends Error {
  constructor(public status: number, message: string) {
    super(message);
  }
}

type Env = Record<string, string | undefined>;
type Headers = Record<string, string | string[] | undefined>;

export function userToken(headers: Headers, env: Env = process.env): string {
  const forwarded = headers['x-forwarded-access-token'];
  const token = (Array.isArray(forwarded) ? forwarded[0] : forwarded) || env.DM_DEV_TOKEN;
  if (!token) {
    // Never fall back to the app's own identity: every player would become the same player.
    throw new HttpError(401, 'No player token: open the game through Databricks Apps (or set DM_DEV_TOKEN locally).');
  }
  return token;
}

export type Archetype = 'warrior' | 'mage' | 'bard';
export interface TurnInput {
  message?: string;
  newGame?: { name: string; archetype: Archetype };
  listAdventures?: boolean;
}

export function invocationBody(input: TurnInput, sessionId: string, stream: boolean): object {
  let body: Record<string, unknown>;
  if (input.listAdventures) body = { list_adventures: true };
  else if (input.newGame) body = { messages: [], new_game: input.newGame, client_session_id: sessionId };
  else body = { messages: input.message ? [{ role: 'user', content: input.message }] : [] };
  return { id: randomUUID(), session_id: sessionId, stream, input: body };
}

export function filterSSE(buffer: string): { out: string; rest: string } {
  const blocks = buffer.split('\n\n');
  const rest = blocks.pop() ?? '';
  const out = blocks
    .filter((b) => {
      const ev = b.split('\n').find((l) => l.startsWith('event:'));
      return ev !== undefined && FORWARD_EVENTS.has(ev.slice(6).trim());
    })
    .map((b) => `${b}\n\n`)
    .join('');
  return { out, rest };
}

export function normaliseHost(h: string): string {
  const withScheme = h.startsWith('http') ? h : `https://${h}`;
  return withScheme.replace(/\/+$/, '');
}

let cachedDmUrl: string | undefined;

export async function resolveDmUrl(env: Env = process.env, fetchFn: typeof fetch = fetch): Promise<string> {
  if (env.DM_URL) return env.DM_URL.replace(/\/+$/, '');
  if (cachedDmUrl) return cachedDmUrl;
  const host = normaliseHost(env.DATABRICKS_HOST ?? '');
  const basic = Buffer.from(`${env.DATABRICKS_CLIENT_ID}:${env.DATABRICKS_CLIENT_SECRET}`).toString('base64');
  const tok = await fetchFn(`${host}/oidc/v1/token`, {
    method: 'POST',
    headers: { Authorization: `Basic ${basic}`, 'Content-Type': 'application/x-www-form-urlencoded' },
    body: 'grant_type=client_credentials&scope=all-apis',
  });
  if (!tok.ok) throw new HttpError(502, 'Could not authenticate the game app to look up the Dungeon Master');
  const { access_token } = (await tok.json()) as { access_token: string };
  const app = await fetchFn(`${host}/api/2.0/apps/${env.DM_APP_NAME ?? 'agent-bricks-dm'}`, {
    headers: { Authorization: `Bearer ${access_token}` },
  });
  if (!app.ok) throw new HttpError(502, 'Could not find the Dungeon Master app (is agent-bricks-dm deployed?)');
  const { url } = (await app.json()) as { url: string };
  cachedDmUrl = url.replace(/\/+$/, '');
  return cachedDmUrl;
}
```

```typescript
export interface StreamEvent {
  event: string;
  data: any;
}

export function parseSSE(buffer: string): { events: StreamEvent[]; rest: string } {
  const blocks = buffer.replace(/\r\n/g, '\n').split('\n\n');
  const rest = blocks.pop() ?? '';
  const events: StreamEvent[] = [];
  for (const block of blocks) {
    let event = 'message';
    const data: string[] = [];
    for (const line of block.split('\n')) {
      if (line.startsWith('event:')) event = line.slice(6).trim();
      else if (line.startsWith('data:')) data.push(line.slice(5).trim());
    }
    if (!data.length) continue;
    try {
      events.push({ event, data: JSON.parse(data.join('\n')) });
    } catch {
      // ignore malformed blocks rather than breaking the turn
    }
  }
  return { events, rest };
}
```

```typescript
  type: string;
  summary: string;
  detail?: any;
}

export interface GameSnapshot {
  character: { name: string; archetype: string; hp: number; max_hp: number; might: number; wits: number; charm: number; gold: number; xp: number; inventory: string[] };
  location_id: string;
  location_name: string;
  exits: { id: string; name: string }[];
  flags: Record<string, string>;
  npcs: { npc_id: string; name: string; disposition: number }[];
  traces_url: string | null;
}

export interface GameView {
  sessionId: string;
  narration: string;
  choices: string[];
  events: TurnEvent[];
  nodes: string[];
  game?: GameSnapshot;
  busy: boolean;
  error?: string;
  startedAt?: number;
  elapsedMs?: number;
  gameOver?: string | null;
  history: string[];
}

const HISTORY_LIMIT = 20;
const keep = (lines: string[]) => lines.slice(-HISTORY_LIMIT);

export const newView = (sessionId: string): GameView => ({
  sessionId, narration: '', choices: [], events: [], nodes: [], busy: false, history: [],
});

export function startTurn(v: GameView, now: number, playerText?: string): GameView {
  return {
    ...v, busy: true, error: undefined, nodes: [], events: [], startedAt: now, elapsedMs: undefined,
    history: playerText ? keep([...v.history, `> ${playerText}`]) : v.history,
  };
}

export function failTurn(v: GameView, message: string): GameView {
  return { ...v, busy: false, error: message };
}

export function applyEvent(v: GameView, e: StreamEvent, now: number): GameView {
  switch (e.event) {
    case 'node':
      return { ...v, nodes: [...v.nodes, String(e.data.node)] };
    case 'turn': {
      const t = e.data.turn ?? {};
      return {
        ...v, narration: t.narration ?? '', choices: t.choices ?? [], events: t.events ?? [],
        gameOver: t.game_over ?? null, history: keep([...v.history, t.narration ?? '']),
      };
    }
    case 'game':
      return { ...v, game: e.data.game };
    case 'run.completed':
      return { ...v, busy: false, elapsedMs: v.startedAt !== undefined ? now - v.startedAt : undefined };
    case 'run.failed':
      return failTurn(v, 'The realm shudders and the Dungeon Master loses the thread. Try again.');
    default:
      return v;
  }
}
```

```typescript
export interface Adventure {
  session_id: string;
  client_session_id: string | null;
  name: string;
  archetype: string;
  location_id: string;
  status: string;
}

  newGame?: { name: string; archetype: 'warrior' | 'mage' | 'bard' };
}

export async function listAdventures(): Promise<Adventure[]> {
  const r = await fetch('/api/adventures');
  if (!r.ok) throw new Error((await r.json().catch(() => ({}))).error ?? `HTTP ${r.status}`);
  return (await r.json()).adventures as Adventure[];
}

export async function playTurn(sessionId: string, input: TurnRequest, onEvent: (e: StreamEvent) => void): Promise<void> {
  const r = await fetch('/api/turn', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ sessionId, ...input }),
  });
  if (!r.ok || !r.body) throw new Error((await r.json().catch(() => ({}))).error ?? `HTTP ${r.status}`);
  const reader = r.body.getReader();
  const decoder = new TextDecoder();
  let buffer = '';
  let completed = false;
  for (;;) {
    const { done, value } = await reader.read();
    if (done) break;
    const { events, rest } = parseSSE(buffer + decoder.decode(value, { stream: true }));
    buffer = rest;
    for (const e of events) {
      if (e.event === 'run.completed' || e.event === 'run.failed') completed = true;
      onEvent(e);
    }
  }
  if (!completed) throw new Error('The connection to the realm faltered mid-turn.');
}
```

```tsx
import { useCallback, useEffect, useRef, useState } from 'react';
import { playTurn, type TurnRequest } from './api';
import { ScryingGlass } from './ScryingGlass';
import { applyEvent, failTurn, newView, startTurn, type GameView } from './state';

export function GameScreen({ sessionId, newGame, onQuit }: {
  sessionId: string;
  newGame?: TurnRequest['newGame'];
  onQuit: () => void;
}) {
  const [view, setView] = useState<GameView>(() => newView(sessionId));
  const [glassOpen, setGlassOpen] = useState(true);
  const [text, setText] = useState('');
  const started = useRef(false);

  const send = useCallback(async (input: TurnRequest, playerText?: string) => {
    setView((v) => startTurn(v, Date.now(), playerText));
    try {
      await playTurn(sessionId, input, (e) => setView((v) => applyEvent(v, e, Date.now())));
    } catch (err) {
      setView((v) => failTurn(v, err instanceof Error ? err.message : String(err)));
    }
  }, [sessionId]);

  useEffect(() => {
    if (started.current) return;
    started.current = true;
    void send(newGame ? { newGame } : { message: '' });
  }, [newGame, send]);

  const act = (msg: string) => {
    const m = msg.trim();
    if (!m || view.busy) return;
    setText('');
    void send({ message: m }, m);
  };

  const c = view.game?.character;
  return (
    <div className="b game-screen">
      <main className="story">
        <div className="frame">
          <div className="bview" data-location={view.game?.location_id ?? 'unknown'}>
            <img src={`/images/${view.game?.location_id}.webp`} alt="" onError={(e) => ((e.target as HTMLImageElement).style.display = 'none')} />
            <span className="scene-name">{view.game?.location_name ?? 'The Kingdom of Sparkia'}</span>
          </div>
        </div>
        <div className="frame narration" aria-live="polite">
          {view.narration ? view.narration.split('\n\n').map((p, i) => <p key={i}>{p}</p>) : <p className="pending">The mists part…</p>}
          {view.error && (
            <p className="warn">
              {view.error} <button className="bbtn inline" onClick={() => act(text || 'I look around')}>Try again</button>
            </p>
          )}
          {view.gameOver && <p className="game-over">— {view.gameOver === 'victory' ? 'Victory!' : 'Your tale ends here.'} —</p>}
          <div className="choices">
            {view.choices.map((ch) => (
              <button key={ch} className="bbtn" disabled={view.busy} onClick={() => act(ch)}>{ch}</button>
            ))}
          </div>
          <input className="parchment-input" value={text} disabled={view.busy} placeholder={view.busy ? 'The DM ponders…' : '…or type what you do'}
                 onChange={(e) => setText(e.target.value)} onKeyDown={(e) => e.key === 'Enter' && act(text)} />
        </div>
        <div className="frame sheet">
          {c ? (
            <>
              <strong>{c.name.toUpperCase()}</strong> · {c.archetype} · HP <span className="hp">{'▮'.repeat(Math.max(0, Math.round((c.hp / c.max_hp) * 9)))}{'▯'.repeat(9 - Math.max(0, Math.round((c.hp / c.max_hp) * 9)))}</span> {c.hp}/{c.max_hp} · M{c.might >= 0 ? '+' : ''}{c.might} W{c.wits >= 0 ? '+' : ''}{c.wits} C{c.charm >= 0 ? '+' : ''}{c.charm} · {c.gold} gp
              <div className="pack">🎒 {c.inventory.join(', ') || 'empty-handed'}</div>
            </>
          ) : 'Reading your character sheet…'}
          <button className="bbtn inline quit" onClick={onQuit}>Leave ▸</button>
        </div>
      </main>
      <ScryingGlass view={view} open={glassOpen} onToggle={() => setGlassOpen(!glassOpen)} />
    </div>
  );
}
```
