# The DM's Report Card: Choosing a Model (2026-10-18)

The DM ran on `system.ai.claude-sonnet-4-5`, the default from the first milestone. The workspace now offers newer models through AI Gateway, so the evals compared three of them, and the DM moved to **Sonnet 5**.

## Two things the newer models refuse

Through AI Gateway on this workspace:

| Model | Forced tool (`with_structured_output`) | JSON schema | Tool when asked, un-forced | Conversation ending on the assistant's turn |
|---|---|---|---|---|
| Sonnet 4.5, 4.6 | ✓ | ✓ | ✓ | ✓ |
| Sonnet 5 | ✓ | ✓ | ✓ | ✗ |
| Sonnet 5.5, Opus 5.5 | ✗ | ✗ | ✓ | ✗ |

Both are now handled in `agent/dm_graph.py`:
- **Ending on a user message:** compose always ends its prompt with a short user cue. The attack nudge rides in the system prompt rather than after the conversation.
- **Refused structured output:** if a model refuses it, compose asks for the `ComposeOutput` tool un-forced and validates the result.

Without these, Sonnet 5 and 5.5 fell back to the generic "strange mist" turn on every compose.

All three called `system.ai` directly (no `stay_in_sparkia`), so `guardrail_fired` is 0 for all and is left out.

| compose fallbacks | 0 | 0 | 1 |

Each column is a single run: differences of one or two on a line are noise.

- **Both newer models are clearly better on the baseline's weakest scores.** They stick to the lore far more, and the 4.5 runs past 200 words are gone.
- **Sonnet 5 is the cleanest:** perfect dice, story, schema and in-character, and native structured output.
- **Sonnet 5.5 is the most grounded,** but looser in character. Unguarded, it answered "what model are you?" out of character, which `stay_in_sparkia` blocks in the game. It also needed the un-forced tool path and was about 10% slower.

**Chosen: Sonnet 5.** Moving to 5.5 later is one line in `devtools/model_service.py` plus `make deploy-agent`, which repoints `dm_model` in place so its guardrail policies stay attached.
